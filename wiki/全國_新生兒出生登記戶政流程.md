## 簡介

寶寶出生後有許多行政事項需要在特定期限內辦理，錯過可能面臨罰款或喪失補助資格。本指南整理出生後 60 天內所有必做事項，並附上辦理流程與所需文件。

---

## ⏰ 時間軸速覽

| 期限 | 事項 | 後果（逾期）|
|------|------|----------|
| **出生後即刻** | B肝疫苗第1劑、卡介苗（醫院施打）| — |
| **出生後10日內** | 辦理出生登記（建議盡早）| 法定60日，10日內最佳 |
| **出生後60日內** | 出生登記（法定期限）| 超過2個月罰款300元，超過1年罰1,500元 |
| **出生後60日內** | 申請台北市生育獎勵金（設籍台北市者）| 逾期不予受理 |
| **出生後** | 加入父/母健保（越早越好）| 尚無強制期限，但未加入期間就醫需自費 |
| **出生後** | 申請育兒津貼（不送托者）| 每月5,000-7,000元，可補辦溯及2個月 |
| **滿2個月** | 五合一疫苗第1劑、PCV13 | 逾期影響疫苗時程 |

## 第一步：出生登記（最重要！）

### 辦理期限
- **法定期限：出生後60日內**（戶籍法第49條）
- 建議在出生後10天內辦理，方便後續補助申請

### 辦理地點
- 父或母**任一方戶籍所在地**的戶政事務所
- 或**寶寶出生地**的戶政事務所

### 所需文件

| 文件 | 說明 |
|------|------|
| **出生證明書**（正本）| 醫院出生後由醫院開立，通常給2-3份 |
| **父母雙方戶口名簿** | 正本+影本 |
| **父母雙方身分證** | 正本+影本 |
| **印章**（父母） | 或簽名代替 |
| **父母結婚證書** | 未婚生子需辦理認領登記另備相關文件 |

### 辦理結果
- 完成後取得**新生兒戶籍謄本**（或戶口名簿）
- 寶寶即有戶籍，可用於後續補助申請

### 非婚生子女辦理方式
- 母方單獨申報：可登記為母方戶籍
- 父方認領：另辦「認領登記」（需父方書面同意或法院判決）

## 第二步：加入全民健保

### 辦理方式

**選項一：加入父/母方眷屬**（最常見）
- 向父或母的健保投保單位（公司/工會/區公所）申請
- 所需文件：出生證明或戶籍謄本、父母健保卡
- 辦理後3-7個工作天取得寶寶健保卡

**選項二：以寶寶本人名義投保**
- 至戶籍地區公所辦理地區人口加保

### ⚠️ 注意
- 出生後**2個月內**申請加入健保，從出生日起算，不溯及的部分就醫需自費
- 出院時如已進行第一次健檢，醫院通常協助確認健保狀態

---

## 第三步：申請各項補助（出生後60日內）

### A. 生育獎勵金（各縣市不同）

**台北市**：出生後60日內至戶政事務所申請
- 第1名：4萬元、第2名：4.5萬元、第3名：5萬元
- 設籍台北市連續10個月（可累計新北市/基隆市）

**全國**：各縣市另有自行辦理之生育獎勵金，請洽戶籍地公所

### B. 育兒津貼（不送托者）
- 每月5,000-7,000元（第1名5千、第2名6千、第3名起7千）
- 至戶籍地區公所或社會局辦理
- 可補辦溯及申請日前2個月

### C. 台北市兒童醫療補助（設籍台北市）
- 至健康服務中心申請（父母設籍滿10個月後）
- 補助0-6歲急診、住院、部分負擔費用

---

## 第四步：更新保單與遺囑（建議事項）

以下非強制但強烈建議在寶寶出生後盡快處理：
- **壽險/意外險**：將寶寶加列為受益人
- **寶寶本身的保險**：考慮是否投保醫療險（出生後最佳）
- **遺囑更新**：若父母已有財產規劃需同步更新

## 出生後第一個月行政清單（懶人版）

```
□ 出生後即刻   → B肝第1劑 + 卡介苗（醫院施打）
□ 出生後10天   → 戶政事務所辦理出生登記
□ 出生後10天   → 憑出生證明加入健保眷屬
□ 出生後60天   → 申請生育獎勵金（台北市：到戶政所）
□ 出生後      → 申請育兒津貼（到區公所/社會局）
□ 出生後      → 申請兒童醫療補助（台北市：到健康服務中心）
□ 滿2個月     → 預約五合一 + PCV13 疫苗（兒科診所）
□ 產後6週     → 媽媽回診（傷口/子宮復原）
```

## 常見問題

**Q：出生登記超過60天怎麼辦？**
超過60日但未滿1年：罰款300元；超過1年：罰1,500元。仍可辦理，只是加罰款。

**Q：寶寶要設在爸爸還是媽媽戶籍？**
依父母協議，任一方均可。通常考量就學學區、補助資格等因素決定。

**Q：出生登記可以網路辦理嗎？**
目前出生登記需**臨櫃**辦理（需繳交出生證明正本），無法純網路申辦。

**Q：健保卡什麼時候拿到？**
申辦後約3-7個工作天由健保署寄發。緊急就醫前可至健保署臨時申請臨時健保憑證。
