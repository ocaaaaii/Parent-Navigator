## 簡介

台灣政府針對 0～12 歲兒童提供完整的**公費疫苗**接種計畫，涵蓋 B 肝、卡介苗、五合一、肺炎鏈球菌、水痘、MMR、日本腦炎、流感、A 肝等疫苗。依時程接種可全程免費，逾時接種需自費補打。

> 官方時程表（11401版，2025年1月）可下載：[現行兒童預防接種時程表_中文.pdf](https://www.cdc.gov.tw/File/Get/xrvB0rEniERWTvRq-p_pww)

## 嬰幼兒公費疫苗接種時程

| 接種年齡 | 疫苗項目 | 劑次說明 |
|---------|---------|---------|
| **出生24小時內** | B型肝炎疫苗（HepB） | 第1劑 |
| **出生24小時內** | 卡介苗（BCG） | 第1劑（唯一一劑） |
| **滿1個月** | B型肝炎疫苗（HepB） | 第2劑 |
| **滿2個月** | 五合一疫苗（DTaP-Hib-IPV） | 第1劑 |
| **滿2個月** | 13價肺炎鏈球菌疫苗（PCV13） | 第1劑 |
| **滿4個月** | 五合一疫苗（DTaP-Hib-IPV） | 第2劑 |
| **滿4個月** | 13價肺炎鏈球菌疫苗（PCV13） | 第2劑 |
| **滿6個月** | 五合一疫苗（DTaP-Hib-IPV） | 第3劑 |
| **滿6個月** | 13價肺炎鏈球菌疫苗（PCV13） | 第3劑 |
| **滿6個月** | B型肝炎疫苗（HepB） | 第3劑 |
| **每年秋冬（滿6個月起）** | 季節性流感疫苗（Influenza） | 每年1劑（首次接種兩劑） |
| **滿12個月** | 水痘疫苗（Varicella） | 第1劑 |
| **滿12個月** | 麻疹腮腺炎德國麻疹（MMR） | 第1劑 |
| **滿12個月** | 日本腦炎疫苗（JE，不活化） | 第1劑 |
| **滿12個月** | A型肝炎疫苗（HepA，106年後出生者）| 第1劑 |
| **滿15個月** | 13價肺炎鏈球菌疫苗（PCV13） | 追加第4劑 |
| **滿18個月** | 五合一疫苗（DTaP-Hib-IPV） | 追加第4劑 |
| **滿24個月** | 日本腦炎疫苗（JE，不活化） | 第2劑 |
| **滿24個月** | A型肝炎疫苗（HepA，106年後出生者）| 第2劑 |
| **滿27個月** | 日本腦炎疫苗（JE，不活化） | 第3劑 |

## 學童追加接種

| 接種年齡 | 疫苗項目 | 說明 |
|---------|---------|------|
| **小學一年級（約6-7歲）** | MMR 第2劑 | 補強麻疹、腮腺炎、德國麻疹 |

| **小學五年級（約11歲）** | Tdap-IPV（減量百日咳混合疫苗）| 青少年追加 |

## 現行公費疫苗完整清單

| 疫苗名稱 | 預防疾病 |
|---------|---------|
| B型肝炎疫苗（HepB） | B型肝炎 |
| 卡介苗（BCG） | 結核病 |
| 五合一（DTaP-Hib-IPV） | 白喉、百日咳、破傷風、b型嗜血桿菌、小兒麻痺 |
| 13價肺炎鏈球菌（PCV13） | 肺炎鏈球菌感染症 |
| 水痘疫苗（Varicella） | 水痘（帶狀疱疹前驅）|
| MMR | 麻疹、腮腺炎、德國麻疹 |
| 日本腦炎疫苗（JE） | 日本腦炎 |
| A型肝炎疫苗（HepA） | A型肝炎（106年後出生者）|
| 季節性流感疫苗 | 流行性感冒 |
| DTaP-IPV / Tdap-IPV | 白喉、百日咳、破傷風、小兒麻痺（學齡追加）|

## 申請時間（時序重點）

| 時間點 | 事項 |
|--------|------|
| 出生24小時內 | B肝第1劑、卡介苗（醫院直接施打）|
| 滿2個月 | ⚠️ 五合一、肺炎鏈球菌開始，請預約兒科 |
| 滿6個月後秋冬 | 每年流感疫苗（首次需打2劑，間隔4週）|
| 滿12個月 | 水痘、MMR、日本腦炎、A肝 同時開始 |
| 小學入學前 | 確認疫苗接種紀錄是否齊全 |

---

## 注意事項

- 公費疫苗**依時程接種免費**；逾齡者需自費補打
- 可使用 [嬰幼兒預防接種時間試算](https://www.cdc.gov.tw/Vaccine/Index/M3lMd2tkMlVTUXMwVDc4MXk3L3dYZz09) 計算個人接種時間
- 接種紀錄登載於**兒童健康手冊**，請妥善保存
- 接種後如有嚴重不良反應，可申請[預防接種受害救濟](https://www.cdc.gov.tw/Category/List/W2EoTuScoXvFk8a2KpFXeA)
- 自費疫苗（如輪狀病毒、腦膜炎雙球菌等）需另行評估
